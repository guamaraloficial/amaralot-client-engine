# Code signing policy - draft, pending review

The repository owner submitted an eligibility inquiry through the SignPath
Foundation application form on 2026-10-18; the form displayed a submission
confirmation. This records submission only, not acceptance of the project.
No SignPath sponsorship or signing approval has been granted.
Do not claim that SignPath signs, approves or endorses this project.

Before a production signing request can proceed, the project needs an eligible publicly reviewable source tree,
a verifiable build, confirmation of upstream/fork eligibility, documented runtime
data handling, and named maintainers/reviewers/approvers using multi-factor
authentication. These roles and identities must be supplied by the project owner.

The applicable current rules are https://signpath.org/terms.html . In particular,
the Foundation's conditions for modified upstream software must be resolved; a
locally available MIT source tree alone does not establish eligibility.

After approval, releases should be built from an approved source commit, signed
through the provider, timestamped, verified, and packaged without further changes
to signed binaries. No private keys or signing credentials belong in this tree.

This draft must be completed and eligibility clarified before any production
signing request or sponsorship announcement. Do not resubmit the inquiry while
the existing submission is awaiting a response.
